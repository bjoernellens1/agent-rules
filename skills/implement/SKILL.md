# implement

Confirm ownership, baseline and local conventions. Reproduce bug or establish behavior first. Implement the simplest working slice, reuse existing code and keep interfaces stable. Run focused checks and expand only when warranted. Inspect diff for unintended changes, secrets, generated artifacts and test weakening. Report changed files and actual checks; coordinator handles shared integration.
