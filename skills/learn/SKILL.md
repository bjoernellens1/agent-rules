# learn

Append a scoped finding and concrete evidence using the learn command. Do not log secrets or private information. Curate at milestones: deduplicate, verify against code/runs, mark stale facts, convert repeated errors into tests/tools or skill updates. Propose rule changes for human approval; do not edit policies or weaken gates automatically. Keep context small, searchable and reversible.
