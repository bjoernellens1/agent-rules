# handoff

Fill HANDOFF.md with objective, actual commit/worktree/dirty state, changed files, executed checks, artifact paths and active job IDs. Record unresolved failures, next actionable command and conditions for ownership transfer. Do not start competing writes while another worker owns the component. Keep the handoff short and link existing evidence instead of duplicating reports.
