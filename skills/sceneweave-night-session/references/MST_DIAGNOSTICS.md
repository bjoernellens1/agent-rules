# MST geometry forensics — mandatory before model expansion

Observed in `fig_v25_night_lane_c_mst.png` (ScanNet++ bf50f418ba, 50% causal progress): completion points form regular rectangular lattices and extend beyond apparent observed boundaries; oracle best-of-K and selected curves almost overlap; localization error ~0.25 m vs ~0.16 m observed baseline; Brier/ECE ~0.46, top-K survival 0.25. The figure is not proof of a specific transform or containment bug. Apparent wall crossings require a 3D/height-aware check, including doors, unobserved adjacent rooms, registration and room-belief uncertainty.

## Forensic order

1. Verify plotted points and reference share units, handedness, transforms, floor plane, and BEV projection. Plot raw fragment, canonical template, transformed template, world placement, measured free/occupied/unknown, predicted hull and independent reference separately. Distinguish analytic box/grid proxies from real object surfaces. Check template origin, centroid vs extent, axis convention, yaw, scale, and compose/invert transforms. Check deterministic synthetic known-pose round trip.
2. Audit causal segmentation: do fragments contain wall/floor points? Plot fragment instance masks and 3D support in RGB and BEV; measure instance precision/recall, centroid/bbox error, ground-truth-assisted crop as offline diagnostic only. Exclude structural surfaces before clustering unless explicitly modeling structural objects. Do not assume semantic labels from spatial bins.
3. Decompose the bottleneck with offline diagnostic stages: observed fragment only; correct instance crop with causal evidence; correct template identity; correct transform; actual online path. Freeze library before test, no future trajectory geometry, no same-instance leakage except explicitly taught prior observations. Oracle best-of-K is only an upper bound over the available candidates; report effective K, uniqueness, diversity, and oracle-vs-selected gap.
4. Apply physical consistency: uncertainty-aware room/portal containment, measured free-space ray contradiction, support/contact, plausible scale, overlap with observed points, and height. Do not blindly clip to a predicted room polygon (open doors and adjacent rooms are possible). Reject rather than paste infeasible geometry. No predicted geometry may update verified TSDF/occupancy. Preserve reversible groups and immutable dependencies.
5. Evaluate fixed early-region prediction accuracy and time-varying missing-region precision/recall separately. If missing region is empty, report NOT_APPLICABLE, not zero F1. At each prefix report correct added surface area, incorrect added surface area, missing region size, absolute precision/recall, localization error, calibration, acceptance/abstention including in-library false rejects and OOL true rejects. Record contradiction event counts and time to retraction; no events is NOT_EVALUATED. Compare against a causal extruded-fragment/box or symmetry baseline, not just an observed-only zero-completion baseline.
6. Stop production insertion until meaningful precision and calibrated prediction pass frozen dev criteria. Visual review must flag implausible placements even if numerical gates pass. Prefer improving actual fragments/template geometry/alignment before increasing candidate count or training a generative model.
