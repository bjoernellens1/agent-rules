# research

Define the specific decision and constraints. Inspect existing code and prior results first. Use primary sources and executable compatibility probes where useful. Compare viable alternatives by capability, performance evidence, licensing, portability and maintenance. Distinguish measured, reported, estimated and unknown. Return a recommendation, rejected alternatives, citations and the smallest resolving experiment.
