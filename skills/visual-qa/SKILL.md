# visual-qa

Capture before/after from the actual matched baseline/head, same scene, frame, camera, seed, settings, resolution and build. Include relevant failure cases and edge states; for mapping use RGB, depth/TSDF and provenance where appropriate. Open and inspect outputs, not just file existence. Preserve private data boundaries. Label revisions, artifacts, differences and limitations. Do not claim visual validation for uninspected media.
